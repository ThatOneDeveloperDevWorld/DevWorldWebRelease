# Dev World
Dev world, in itself, is just a small project. But when you think about it, isn't an app made entirely with android 12+ impressive? Let's be honest about that.

## things about DEV WORLD
1. **Editor:** Make, Play, and Publish games all from one menu.


## Platforms
1. **Mobile:** main platform, used by the creator and most users.
2. **PC:** Available only for the web version, dev world is usable on PC. Though currently, no executable EXE file exists for dev world on PC.
